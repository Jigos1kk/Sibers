# Sibers Test

Проект тестового задания для компании Sibers. Веб-приложение для управления проектами и задачами с разделением на backend ASP.NET Core и frontend на React.

## Технологии

### Backend
- **.NET 10.0** - современная платформа для разработки
- **ASP.NET Core** - веб-фреймворк для создания API
- **Entity Framework Core 10.0** - ORM для работы с базой данных
- **SQLite** - легковесная база данных
- **ASP.NET Core Identity** - система аутентификации и авторизации
- **OpenAPI/Swager** - документация API

### Frontend
- **React 19** - библиотека для построения пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript
- **Vite** - быстрый сборщик и dev-сервер
- **Tailwind CSS 4** - utility-first CSS фреймворк
- **React Icons** - библиотека иконок

### Архитектура
Backend построен по принципам Clean Architecture:
- **Domain** - сущности и бизнес-правила
- **Application** - сервисы, DTO, валидаторы
- **Data** - репозитории, конфигурации EF Core, миграции
- **API** - контроллеры и точка входа

## Функциональность

- Управление проектами (создание, редактирование, фильтрация, сортировка)
- Управление сотрудниками
- Управление задачами проектов
- Отслеживание статусов задач
- Валидация данных на backend и frontend

## Предварительные требования

Перед запуском убедитесь, что у вас установлены:

- **.NET 10.0 SDK**
- **Node.js 18+** и **npm**

## Установка и запуск

### 1. Установка зависимостей

```bash
# Установка зависимостей для frontend
cd src/SibersTest.Web && npm install
```

### 2. Запуск проекта в режиме разработки

```bash
# Запуск backend и frontend одновременно
npm run dev
```

Эта команда запустит:
- **Backend API** на `http://localhost:5281`
- **Frontend** на `http://localhost:5173`

### 4. Сборка проекта

```bash
# Сборка backend и frontend
npm run build
```

Или сборка отдельных частей:

```bash
# Только backend
dotnet build

# Только frontend
npm run build --prefix src/SibersTest.Web
```

## API Документация

После запуска backend документация API доступна по адресу:
- Scalar: `http://localhost:5281/api-docs`

## База данных

Проект использует SQLite базу данных. Файл базы данных создается автоматически при первом запуске. Миграции применяются автоматически.

Основные сущности:
- **Company** - компании
- **Employee** - сотрудники
- **Project** - проекты
- **ProjectTask** - задачи проектов
